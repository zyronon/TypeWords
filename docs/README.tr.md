## Özellik Listesi

### Kelime Pratiği

- Pratik modları: Takip yazımı / Yazdırma / Kendini test etme / Ezberden yazma
- Akıllı mod: Hafıza eğrilerine dayanarak öğrenilecek kelimeleri otomatik hesaplar, yazdırma ile hafızayı pekiştirir
- Serbest mod: Kısıtlama yok, kendi öğrenmeni kendin planla
- Fonetik, telaffuz (Amerikan/Britanya), örnek cümleler, deyimler, eş anlamlılar, kök kelimeler, köken bilgisi, hata istatistikleri ve fazlası

### Makale Ezberi

- Hazır klasik ders kitapları; kendi makalelerini tek tıkla çeviri ve iki dilli karşılaştırma ile ekleyebilirsin
- Takip yazımı + yazdırma çift modu, cümle cümle yazım ve otomatik telaffuz ile ezberi daha verimli kılar
- Dinlerken ezberden yazmayı destekler, böylece hatırlama pekişir

### Favoriler, Hatalı Kelimeler, Öğrenilenler

- Öğrenirken yanlış yazılan kelimeler, sonradan tekrar edebilmen için otomatik olarak hata defterine eklenir
- Öğrendiklerini öğrenilenlere kendin ekle, sonraki oturumlarda otomatik olarak atlanır
- Tekrarı pekiştirmek için kelimeleri favorilere ekle

### Yüksek Düzeyde Özelleştirilebilir

- Zengin klavye ses efektleri
- Özelleştirilebilir kısayollar
- Yüksek düzeyde yapılandırılabilir ayarlar

### Sade ve Verimli

- Temiz tasarım, modern arayüz, reklamsız
- Sade arayüz, kolay kullanım
- Hiçbir platforma zorunlu abonelik yok

### Kelime Kütüphanesi

CET-4, CET-6, GMAT, GRE, IELTS, SAT, TOEFL, yüksek lisans İngilizcesi, TEM-4, TEM-8 ve daha fazlası için gömülü yaygın kelime hazinesi (yalnızca resmî site).
Çoğu kullanıcının kelime öğrenme ihtiyacını karşılamak üzere tasarlandı. Topluluktan ek kelime katkıları kabul edilir.

## Projeyi Çalıştırma

#### Not: Bu proje verileri yerel olarak saklayarak bağımsız çalışabilir. Cihaz değiştirirken manuel yedek alınması gerekir; normal kullanımı etkilemez.
Bu proje `Nuxt` ile geliştirilmiştir ve bir Node.js ortamı gerektirir.

1. NodeJS kurun, [resmî doküman](https://nodejs.org/en/download) sayfasına bakın
2. Proje büyüktür. Yalnızca son commit'i klonlamak için `git clone --depth 1 https://github.com/zyronon/TypeWords.git` kullanmanız önerilir. GitHub'ın Download ZIP özelliği düzgün çalışmaz.
3. Proje kök dizininde bir terminal açın ve bağımlılıkları indirmek için `pnpm install` çalıştırın.
4. Projeyi başlatmak için `pnpm run dev` çalıştırın. Varsayılan adres [`http://localhost:5567`](http://localhost:5567)
5. Projeye erişmek için tarayıcınızda [`http://localhost:5567`](http://localhost:5567) adresini açın.
6. Proje dosyalarını derlemek için `pnpm run generate` çalıştırın.
