# 认词学习

适合以“看见英文能理解意思”为目标的学习者。

1. 在单词页选择要学习的词典；通过「每日目标 → 更改」设置每组新词数量。
2. 点击单独的「认词学习」按钮。
3. 看英文选择中文释义，点击选项或使用默认快捷键 1、2、3、4。
4. 不认识时点击「不认识，查看答案」，阅读含义后点击「下一个单词」或按空格。

答错的词会加入错词本，并在本组结束时再次以选择题巩固，全程无需拼写。
完成整组后，累计已学单词数、学习时长、正确率和新词/复习数量。
正确和错误回答会接入现有 FSRS 复习安排；巩固答对不会把本组首次答错的词误记为熟练。

中途离开会保存当前练习位置；重新打开单词页可点击「继续认词学习」。
未完成的整组暂不增加词典的已学数量。学习模式会保存在当前浏览器中，
也可随时回到普通学习或自由练习。

本模式与词典详情页的「测试」按钮独立，测试仍用于不计入学习进度的测验。
